### Release Conditions
- **Condition 1 (Research Publication Disclaimer):** Any academic publication, white paper, or presentation utilizing this repository must prominently state that all benchmarks and evaluations were performed on **synthetically generated data** (`data/student_data.csv`).
- **Condition 2 (Institutional Deployment Constraint):** The system **must not** be used for high-stakes educational decisions (e.g., student admission, branch denial, scholarship revocation, career gating) until the pipeline is retrained, recalibrated, and externally audited on an institutionally vetted, IRB-approved longitudinal student cohort.
- **Condition 3 (Advisory-Only Actionable Recourse):** Counterfactual recourse recommendations generated by the system must be presented to students and counselors as **heuristic targets**, not deterministic causal guarantees of campus placement.

## 4. Security & Robustness Verification

1. **OWASP Top 10 Headers Injected:** Verified `Content-Security-Policy`, `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`, `Strict-Transport-Security`, and `Referrer-Policy: no-referrer`.
2. **Denial-of-Service Defense:** `MAX_CONTENT_LENGTH = 1_048_576` prevents memory exhaustion from oversized request payloads.
3. **Strict Pydantic Boundary Rejection:** Unexpected attributes in JSON payloads are rejected with HTTP 422 (`extra="forbid"`).
4. **Path Traversal Mitigation:** Verified directory traversal attacks on report downloads (`/api/export?file=../../etc/passwd`) are blocked via strict filename whitelisting and `os.path.basename()` normalization.
